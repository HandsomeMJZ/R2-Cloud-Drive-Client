# R2 Cloud Drive Client 操作手册

## 1. 软件概述

R2 Cloud Drive Client 是一款基于 Electron 的桌面云盘客户端软件，用于连接 R2 Cloud Drive 服务端，完成云端文件管理、图片相册浏览、大文件上传下载、下载记录管理、自动备份和存储节点管理等操作。

软件适用于需要通过桌面客户端管理 Cloudflare R2 或兼容对象存储中云盘文件的用户。客户端通过服务端 API 与云端存储通信，本地不直接暴露对象存储密钥。

## 2. 主要功能

- 用户登录：支持配置 API 基准地址和访问密码。
- 文件管理：支持浏览、新建文件夹、上传、下载、重命名、删除、复制、剪切和粘贴。
- 相册管理：支持图片和视频目录浏览，提供缩略图和媒体预览。
- 快速访问：支持查看常用文件夹和最近文件。
- 大文件传输：支持普通上传、R2 Multipart 分片上传、分布式上传和 Range 分段下载。
- 传输列表：展示实时上传、实时下载、传输进度、失败原因、取消、重试和下载记录。
- 自动备份：支持选择本地文件夹，按照指定间隔自动备份到云端。
- 存储节点管理：支持新增、测试、查看和删除存储节点。
- 桌面行为设置：支持托盘菜单、任务栏进度、系统通知、最小化行为、关闭行为和启动隐藏。
- 外观设置：支持浅色/深色主题、品牌标识和自定义样式。

## 6. 打包与安装

### 6.1 打 Windows 安装包

```powershell
npm.cmd run dist:win
```

打包完成后，安装包位于：

```text
release-windows/
```

常见产物包括：

- `R2 Cloud Drive Setup 0.1.0.exe`：安装包。
- `R2 Cloud Drive 0.1.0.exe`：便携版。
- `win-unpacked/R2 Cloud Drive.exe`：解包后的程序，可用于快速测试。

### 6.2 安装包测试流程

1. 双击 `R2 Cloud Drive Setup 0.1.0.exe`。
2. 按安装向导完成安装。
3. 检查桌面快捷方式是否生成。
4. 双击桌面快捷方式启动软件。
5. 检查窗口图标、托盘图标、设置页和主要功能是否正常。

## 7. 首次使用流程

### 7.1 打开软件

启动软件后，如果未配置 API 地址，系统会弹出连接窗口。

### 7.2 填写 API 地址

在“API 基准地址”中填写 R2 Cloud Drive 服务端地址，例如：

```text
https://your-worker.example.com
```

### 7.3 测试连接

进入“设置”页面，点击“测试连接”按钮。

- 如果连接正常，系统会提示连接延迟。
- 如果连接失败，系统会提示网络、API 地址或存储节点相关原因。

### 7.4 登录

如果服务端配置了访问密码，在“访问密码”处输入密码；如果服务端未配置访问密码，可以留空。点击登录后进入主界面。

## 8. 文件管理操作

### 8.1 浏览文件

点击左侧“我的云盘”，系统显示当前云盘目录中的文件和文件夹。

### 8.2 新建文件夹

1. 点击“新建”。
2. 选择“新建文件夹”。
3. 输入文件夹名称。
4. 点击确认。

### 8.3 上传文件

1. 进入目标目录。
2. 点击“上传”。
3. 在系统文件选择窗口中选择一个或多个文件。
4. 软件会自动加入传输列表并显示上传进度。
5. 如果上传失败，可在“传输列表”中点击“重试”。

### 8.4 下载文件

1. 在文件列表中选择目标文件。
2. 点击“下载”。
3. 如已设置默认下载路径，文件会自动保存到该路径；否则默认保存到系统下载目录。
4. 下载完成后，系统会发送通知，并可在“已下载文件”中定位本地文件。

### 8.5 删除文件

1. 选择需要删除的文件或文件夹。
2. 点击删除。
3. 在确认窗口中确认删除。

### 8.6 重命名文件

1. 选择一个文件或文件夹。
2. 点击重命名。
3. 输入新名称并保存。

## 9. 相册功能

1. 点击左侧“相册”。
2. 浏览云端相册目录中的图片和视频。
3. 点击图片或视频可进入媒体预览。
4. 可通过“上传到相册”将本地图片或视频上传到相册目录。
5. 可通过“相册备份”选择本地相册文件夹进行备份。

## 10. 传输列表

点击左侧“传输列表”可查看：

- 实时上传任务
- 实时下载任务
- 默认下载路径
- 已下载文件记录

传输任务支持：

- 查看进度
- 取消下载
- 定位已下载文件
- 单个失败任务重试
- 批量重试失败任务
- 清理已完成任务

上传或下载过程中，Windows 任务栏会显示整体传输进度。任务完成后，系统会发送通知。

## 11. 自动备份

### 11.1 添加备份文件夹

1. 点击左侧“自动备份”。
2. 点击“添加文件夹”。
3. 选择本地需要备份的目录。
4. 保存后，软件会按照备份间隔执行备份。

### 11.2 设置备份间隔

1. 在“自动备份”页面设置备份间隔，单位为分钟。
2. 可选择是否开机自启动。
3. 点击“保存设置”。

### 11.3 手动备份

点击“立即备份全部”即可手动执行全部备份任务。

## 12. 存储节点管理

点击左侧“存储节点查看”可进入节点管理页面。

支持操作：

- 新增节点
- 编辑节点地址和 Token
- 启用或禁用节点
- 测试节点可用性
- 删除节点

如果上传出现连接超时或节点不可用，建议先在此页面测试节点状态。

## 13. 设置说明

### 13.1 连接设置

- API 基准地址：服务端 API 地址。
- 测试连接：检测服务端是否可访问。
- 打开共享页：打开服务端共享页面。

### 13.2 桌面行为

- 关闭窗口时：支持每次询问、最小化到托盘、退出程序。
- 最小化按钮：支持最小化到任务栏或隐藏到托盘。
- 启动后隐藏到托盘：适合后台自动备份场景。

### 13.3 下载路径

可设置默认下载目录。未设置时，软件默认使用系统下载目录。

### 13.4 外观设置

支持设置标题图标 HTML 和自定义 CSS。正式发布时建议限制为可信配置，避免不安全的 HTML 内容。

## 14. 常见问题

### 14.1 提示 fetch failed 怎么办？

表示客户端无法访问服务端。请检查：

- API 基准地址是否正确。
- 电脑网络是否正常。
- 服务端是否已部署并运行。
- 防火墙或代理是否阻止访问。
- 存储节点地址是否可用。

### 14.2 提示 connect ETIMEDOUT 怎么办？

表示连接服务器超时。请进入“设置”点击“测试连接”，并进入“存储节点查看”测试节点。如果浏览器也无法打开 API 地址，说明网络或服务端存在问题。

### 14.3 上传失败怎么办？

进入“传输列表”，查看失败原因。可点击单个任务的“重试”，也可以点击“重试失败”批量重试。

### 14.4 下载文件保存在哪里？

如果设置了默认下载路径，文件保存到该目录；如果未设置，文件保存到系统下载目录。下载完成后可在“已下载文件”中点击“定位”。

### 14.5 关闭窗口后软件还在运行怎么办？

如果关闭行为设置为“最小化到托盘”，软件会继续在后台运行。可右键托盘图标选择退出，或在设置中将关闭行为改为“退出程序”。

## 15. 配置项说明

客户端配置保存在 Electron 的用户数据目录中，主要字段包括：

- `baseUrl`：API 基准地址。
- `downloadDir`：默认下载目录。
- `backupJobs`：自动备份任务。
- `backupIntervalMinutes`：自动备份间隔。
- `backupAutoStart`：是否开机自启。
- `closeBehavior`：关闭窗口行为，支持 `ask`、`tray`、`quit`。
- `minimizeBehavior`：最小化按钮行为，支持 `taskbar`、`tray`。
- `startHiddenToTray`：启动后是否隐藏到托盘。
- `customBrandHtml`：自定义品牌 HTML。
- `customBrandCss`：自定义品牌 CSS。
